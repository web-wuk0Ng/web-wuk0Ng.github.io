渗透攻击红队内网域渗透靶场 拓扑结构

攻击端

  • 操作角色：渗透攻击红队人员
  • 攻击设备：
    • Windows 10 个人PC
    • Kali Linux VPS

网络区域拓扑

DMZ区域

  • 边界设备：防火墙
  • 核心服务器：Ubuntu-16 服务器
    • 外网IP：192.168.0.x（DHCP分配，桥接模式）
    • 内网IP：10.0.1.6（仅主机模式）
    • 运行环境：Ubuntu Desktop + Log4j2 环境
  • 链路：攻击端 → DMZ区域

个人办公区

  • 终端设备：Windows 7
    • 内网IP 1：10.0.1.7（仅主机模式，连通DMZ区）
    • 内网IP 2：10.0.0.7（仅主机模式，连通域核心区）
  • 链路：DMZ区域 → 个人办公区

域核心机器

  • 域控制器：Windows 2012
    • 内网IP：10.0.0.12（仅主机模式）
  • 通关目标：域控桌面存放 Flag 文件，成功获取即可通关
  • 链路：个人办公区 → 域核心机器

405 状态码的含义
CODE:405 对应的是 HTTP 标准状态码 405 Method Not Allowed，直译是 “请求方法不被允许”。
它的完整语义是：该路径真实存在，但服务器拒绝了当前使用的 GET 方法，只允许使用其他指定的 HTTP 方法
